One short line about office life — a setup everyone recognises (the printer
that jams on deadline day), a turn nobody sees coming, and the punchline
last. `main.ts` is a self-contained Node 22 program (stdlib only, no network,
no files read) that writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Entry (117 chars, single line):

> The printer jammed on deadline day, so I printed my resignation — it jammed on that too, which is why I'm still here.
